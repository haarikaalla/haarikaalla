<img src="https://img.shields.io/badge/Multi--Agent%20Economies-6C63FF?style=flat-square"/>
<img src="https://img.shields.io/badge/Carbon--Aware%20ML%20Systems-6C63FF?style=flat-square"/>
<img src="https://img.shields.io/badge/Low--Resource%20%26%20Multilingual%20NLP-6C63FF?style=flat-square"/>
</p>

- **Agent orchestration** — coordinating multiple specialist LLM agents (planner, retriever, critic, executor) into a single reliable workflow instead of one monolithic prompt
- **Vision-language & multimodal models (VLMs/VLAs)** — grounding language models in visual and spatial input for perception-driven decision-making, especially for autonomous/robotic agents
- **GraphRAG & knowledge-graph reasoning** — replacing flat vector search with structured, auditable graph memory for higher-trust retrieval
- **LLM observability, evals & guardrails** — tracing, scoring, and versioning LLM behavior as agents gain more autonomy
- **Reasoning & test-time compute** — models that "think longer" at inference time rather than just scaling parameters
- **Model Context Protocol (MCP) & standardized tool-use** — the emerging interoperability layer for how agents connect to tools, data, and each other
- **World models** — learned simulators that let agents plan by predicting outcomes before acting, key for robotics and autonomous systems
- **Persistent agent memory & belief revision** — memory that ages, conflicts, and resolves with provenance, instead of silently overwriting
- **Physics-informed graph neural networks** — embedding domain physics into GNNs to catch cascading failures (climate, infrastructure) before they happen
- **Carbon-aware & sustainable ML systems** — scheduling and infra-level ML optimized for energy footprint, not just latency
- **Low-resource & multilingual NLP** — generative pipelines for languages underserved by mainstream LLMs
